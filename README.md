# python-gems

Python scripts developed while learning through the language.

This repository contains small Python projects and scripts created as learning exercises. Each folder focuses on a practical example that interacts with an external data source or API.

## Repository contents

### Exchange Rate Info
The `Exchange Rate Info` directory contains a script for retrieving up-to-date currency exchange information using the Fixer.io API.

Included files:
- `exchange-rate-info.py` — fetches exchange rate data.
- `config.ini` — stores the API access key used by the script.
- `Pipfile` and `Pipfile.lock` — dependency configuration for running the script.
- `README.md` — notes about the project and usage.

### Weather
The `Weather` directory contains a script for retrieving the latest weather information from the Bureau of Meteorology (Australia) website using web scraping.

Included files:
- `getBomWeather.py` — fetches weather information for a given state and suburb.
- `Pipfile` and `Pipfile.lock` — dependency configuration for running the script.
- `README.md` — notes about the script and how it is used.

## Purpose
These scripts are examples of learning Python through real-world tasks such as:
- consuming APIs
- parsing external web data
- working with configuration files
- building small command-line utilities

## Notes
The repository is intentionally lightweight and educational, with each project focused on a single concept or use case.
